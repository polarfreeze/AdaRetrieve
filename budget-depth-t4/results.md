## 检索和重排深度

BM25 与稠密检索各最多返回 K 篇，RRF 合并去重。候选召回率为每个查询的候选并集覆盖的已标注相关文档比例，再按查询平均。基线为 192-token TinyBERT。每个 K/编码长度组合实测一个公共检索前缀，所有后缀均计入完整前缀耗时和各自实测的重排耗时。重排每次独立打分，同一查询的各条件随机排序。K=20 时并集最多 40 篇，重排 50 配置实际处理该查询可用的全部候选。

## 复核与复现

observations.zip 包含每条查询的前十篇文档、准入路径、时间、源域采样、冻结清单和完整性校验码。将本目录放在第 5 版 project 目录的同级，运行 python budget-depth-t4/analyze.py 可用已校验的原始数据集重算质量、效用和区间，再运行 python budget-depth-t4/make_results.py 生成本页。重测 GPU 时打开 sensitivity-t4.ipynb，上传原来的工程 ZIP 和索引 ZIP，选择 Colab T4 后执行全部单元格。
